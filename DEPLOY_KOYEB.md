# 🚀 Деплой на Koyeb (бесплатно, без «сна»)

Три фазы: **код на GitHub → сервис на Koyeb → chat_id и проверка.**
Терминал не нужен — всё через веб.

## Фаза 1. Код на GitHub
1. Заведи аккаунт на github.com (если ещё нет).
2. **New repository** → имя `wc2026-bot`, **Private** → Create.
3. На странице репозитория: **Add file → Upload files**.
4. Распакуй архив `wc2026-bot-bundle*.zip` и перетащи **содержимое** папки
   (все файлы + папку `data`). Файл `.env` **НЕ** загружай — ключи пойдут в Koyeb.
5. **Commit changes**.

## Фаза 2. Сервис на Koyeb
1. Зайди на koyeb.com, зарегистрируйся (удобно через GitHub-аккаунт).
2. **Create Service → GitHub** → выбери репозиторий `wc2026-bot`.
3. **Service type: Worker** (бот не слушает порт, публичный адрес не нужен).
4. Builder — оставь автоопределение, Koyeb сам увидит `Dockerfile`.
5. Instance — **Free**.
6. **Environment variables** → добавь (значения возьми из своего `.env`):
   - `TELEGRAM_BOT_TOKEN`
   - `ANTHROPIC_API_KEY`
   - `FOOTBALL_DATA_API_KEY`

   Остальное (`SHEET_ID`, `GID_*`, `MODEL_*`, `TIMEZONE`, …) уже зашито по
   умолчанию — добавлять не обязательно.
7. **Deploy**. Дождись статуса **Healthy**, загляни в **Logs** — там должно быть
   «Бот запускается…».

## Фаза 3. chat_id и финальная проверка
1. В @BotFather: `/setprivacy` → выбери бота → **Disable**. Добавь бота в группу.
2. Напиши боту в группе `/chatid` → он пришлёт число (id группы).
3. В Koyeb → сервис → **Settings → Environment variables** → добавь
   `TELEGRAM_CHAT_ID` = это число → Save (Koyeb передеплоит).
4. Проверка в группе: `/table` (живой разбор) и `/next` (ближайшие матчи).
   Дальше анонсы перед матчами и итоги бот шлёт сам.

> Нюанс Koyeb: при передеплое файл состояния обнуляется — изредка возможен
> повторный анонс ближайшего матча. Не критично.
